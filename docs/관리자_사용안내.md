# 포트폴리오 관리자 사용안내

관리자 화면에서 시공 사례와 홈페이지 첫 화면의 사진을 관리할 수 있습니다. 이 안내는 버전 `0.1.2` 변경사항을 포함합니다. 운영 관리자 주소에서 메인 슬라이드쇼 메뉴·기존 사진과 문구 보존·미저장 이동 확인·순서 변경·표시 방식·사진 교체와 저장을 확인했습니다.

## 로그인

관리자 주소는 [admin.designmood.kr](https://admin.designmood.kr)입니다. DNS·HTTPS 연결과 로그인 화면 표시를 확인했습니다. 기본 호스팅 주소 [design-mood-admin-2120.netlify.app](https://design-mood-admin-2120.netlify.app)에서도 접속할 수 있으며, 해당 운영 앱에서 로그인·저장·사진 표시·삭제를 검증했습니다.

승인된 관리자 이메일과 비밀번호로 로그인합니다. 최초 관리자 이메일은 `design_mood_2120@naver.com`입니다. 계정 가입은 꺼져 있으며, 일반 계정은 포트폴리오를 수정할 수 없습니다. 권한이 없다고 표시되면 운영 담당자에게 계정 승인을 요청하세요.

로그인은 접속한 관리자 주소의 브라우저 탭 세션에 저장됩니다. 홈페이지 주소나 다른 관리자 주소로 이동하면 로그인이 공유되지 않습니다. 공용 기기에서는 작업 후 로그아웃하세요.

‘비밀번호를 잊으셨나요?’에서 재설정 이메일을 요청할 수 있습니다. 현재 사용자 지정 SMTP는 설정되지 않았고 이메일 수신은 검증되지 않았습니다. 안내 문구가 표시되더라도 수신이 확인된 것은 아닙니다. 메일을 받지 못하면 운영 담당자에게 계정 복구를 요청하세요.

## 관리 메뉴 선택

‘시공 포트폴리오’는 현장별 사례와 사진 설명을, ‘메인 슬라이드쇼’는 홈페이지 첫 화면의 사진을 관리합니다. 저장하지 않은 내용이 있으면 메뉴 이동 시 변경을 버릴지 확인합니다. 업로드·저장·사진 정리가 진행 중일 때에는 완료를 기다린 뒤 이동하세요.

## 메인 슬라이드쇼 관리

1. ‘메인 슬라이드쇼’ 메뉴를 엽니다. 초기값은 기존 홈페이지 사진 4장입니다.
2. ‘메인 사진 추가’로 사진을 추가하거나 각 항목의 ‘사진 교체’에서 파일을 선택합니다. 사진 교체는 해당 항목의 기존 제목·문구·표시 방식을 유지합니다.
3. ‘짧은 제목’은 80자까지, ‘사진 문구’는 1~200자로 입력합니다. 화면에서는 긴 제목은 최대 2줄, 사진 문구는 최대 3줄로 제한되어 일부가 생략될 수 있습니다.
4. 사진 표시 방식을 선택합니다. ‘프레임 채우기’는 사진의 가장자리가 일부 잘릴 수 있고, ‘사진 전체 보기’는 전체 사진을 표시하면서 여백이 생길 수 있습니다.
5. ‘앞으로’·‘뒤로’로 순서를 바꾸거나 ‘제거’로 목록에서 제외합니다. 사진은 1~10장이며 마지막 1장은 제거할 수 없습니다.
6. ‘메인 슬라이드쇼 저장’을 누르고 홈페이지에서 사진 순서·문구·잘림을 확인합니다.

파일은 JPG·PNG·WebP 형식, 원본 장당 20MB 이하입니다. 업로드 전에 긴 변을 최대 2,400px로 줄이고 WebP로 변환하며 저장 파일은 장당 5MB 이하입니다. 업로드와 편집만으로 홈페이지에 공개되지는 않으며, 저장하면 메인 슬라이드쇼 전체 설정이 공개됩니다. 시공 사례의 비공개·공개 상태와는 별도의 설정입니다.

홈페이지는 새로 열 때, 창으로 돌아올 때와 표시 중 60초마다 저장된 슬라이드쇼를 확인합니다. 처음 설정을 불러오지 못하면 기존 사진 4장을 표시하고, 이후 갱신이 실패하면 현재 슬라이드쇼를 유지합니다. 반영이 늦어지면 홈페이지를 새로고침하세요.

다른 창이나 관리자가 먼저 저장하면 기존 내용을 덮어쓰지 않고 오류를 표시합니다. 작성한 문구를 따로 보관한 뒤 ‘다시 불러오기’로 최신 설정을 열어 다시 반영하세요. ‘다시 불러오기’와 메뉴 이동·로그아웃에서 변경을 버리면 미저장 업로드도 정리합니다. 저장하지 않은 편집 내용이 자동 복구되지는 않습니다.

## 새 시공 사례 등록

1. ‘새 시공 사례’를 누릅니다.
2. ‘아파트 인테리어’처럼 주소를 포함하지 않는 공개 제목을 입력하고 아파트·단독주택·상가/오피스 중 공간 유형을 선택합니다. 아파트명·동·호수 등 주소 정보는 제목에 넣지 않습니다.
3. 필요하면 평수와 시공 설명을 입력합니다. 평수는 1~1,000 사이의 정수이며 생략할 수 있습니다. 위치 입력란과 홈페이지 위치 표시는 제공하지 않습니다.
4. ‘사진 선택하여 업로드’로 현장 사진을 추가합니다.
5. 공개 상태와 표시 순서를 정한 뒤 ‘저장’을 누릅니다.

공개 제목은 100자, 시공 설명은 10,000자까지 입력할 수 있습니다. 새 사례의 기본 상태는 비공개이며, 저장해야 목록에 등록됩니다. 사진 업로드만으로 홈페이지에 공개되지는 않습니다. 기존 사례를 저장하면 예전에 입력한 위치 값도 비웁니다.

## 사진과 표시 순서

- 사례당 최대 20장까지 등록할 수 있습니다.
- 원본은 JPEG·PNG·WebP 형식이며, 파일당 20MB 이하여야 합니다.
- 업로드 전에 긴 변을 최대 2,400px로 줄이고 WebP로 변환합니다. 저장 파일은 장당 5MB 이하입니다. 지나치게 큰 해상도나 읽을 수 없는 사진은 업로드되지 않습니다.
- 첫 번째 사진이 홈페이지 대표 사진입니다. 사진 탭을 선택하면 해당 사진의 제목과 부연설명을 편집할 수 있습니다.
- 사진 제목은 200자, 사진 부연설명은 2,000자까지 입력할 수 있으며 부연설명의 줄바꿈은 공개 상세보기에도 반영됩니다. 선택한 사진에만 적용됩니다.
- 선택한 사진의 ‘앞으로’·‘뒤로’ 버튼으로 순서를 바꿉니다. 사진 제목과 부연설명은 사진과 함께 이동합니다. 사진 탭은 클릭하거나 방향키·Home·End로 선택할 수 있습니다.
- ‘제거’는 편집 중인 사진 목록에서 제외합니다. 저장하면 변경이 반영됩니다.
- 사례의 ‘표시 순서’는 작은 숫자가 먼저 나옵니다. 같은 숫자이면 최근 생성한 사례가 먼저 표시됩니다. -100,000~100,000 사이의 정수를 입력하세요.

업로드 또는 저장 중에는 작업이 끝날 때까지 기다리세요. 일부 사진 업로드가 실패하면 이미 업로드한 사진은 편집 화면에 남으므로, 내용을 확인하고 저장하거나 변경을 버릴 수 있습니다.

## 비공개와 공개

‘비공개 — 관리자만 확인’으로 저장하면 관리자만 사례를 볼 수 있습니다. 사진 없이 초안을 저장할 수 있습니다.

‘공개 — 홈페이지에 표시’로 저장하려면 사진이 최소 1장 필요합니다. 저장 후 ‘홈페이지 보기’에서 공개 제목, 사진, 순서와 설명을 확인하세요. 홈페이지는 처음 열 때와 창으로 돌아올 때 데이터를 불러오고, 표시 중에는 1분 간격으로 다시 확인합니다. 네트워크 상태에 따라 반영이 늦어지면 홈페이지를 새로고침하세요.

공개 사례를 비공개로 바꾸려면 상태를 변경하고 저장합니다. 이미 발급된 사진 링크는 최대 600초 동안 유효할 수 있으며, 이미 내려받은 사진까지 회수하지는 않습니다.

## 홈페이지 사진 설명과 확대보기

사례 상세보기의 ‘사진 설명’ 탭에는 현재 사진의 부연설명이 표시됩니다. 부연설명이 없으면 사진 제목 또는 안내 문구를 표시합니다. ‘시공 소개’ 탭에서는 사례 전체의 시공 설명을 확인할 수 있습니다. 사진을 넘기면 사진 설명도 해당 사진 내용으로 바뀝니다.

사진을 클릭하면 화면을 채우는 확대보기가 열립니다. 처음에는 화면에 맞춰 표시하며 ‘100% 크기’를 누르면 저장된 사진의 실제 픽셀 크기로 전환합니다. 화면보다 큰 사진은 스크롤하여 이동하고 ‘화면 맞춤’으로 돌아갈 수 있습니다. 이전·다음 버튼으로 사진을 넘기면 다시 화면 맞춤 상태로 시작합니다. 화면 맞춤 상태에서는 좌우 방향키로 사진을 넘길 수 있고, 100% 상태에서는 사진 영역에 초점을 둔 뒤 방향키로 스크롤할 수 있습니다.

닫기 버튼이나 Escape를 누르면 확대보기만 닫고 사례 상세보기로 돌아갑니다. 초점은 확대보기를 열었던 사진 버튼으로 돌아갑니다. 상세보기에서 다시 Escape를 누르면 사례 목록으로 돌아갑니다.

‘100% 크기’는 업로드 후 저장된 이미지의 크기를 뜻합니다. 업로드 시 긴 변을 최대 2,400px로 줄이며 이미 줄어든 사진에서 더 높은 원본 해상도를 복원할 수는 없습니다.

## 수정 충돌과 저장하지 않은 내용

목록에서 사례를 선택해 수정한 뒤 저장합니다. 다른 창이나 관리자가 먼저 수정했다면 기존 내용을 덮어쓰지 않고 오류를 표시합니다. 작성한 내용을 따로 복사해 둔 다음 목록을 새로고침하고 최신 사례에 다시 반영하세요. 새로고침은 편집 중인 내용을 버릴지 확인합니다.

사례를 바꾸거나 로그아웃할 때 저장하지 않은 변경사항이 있으면 확인창이 표시됩니다. 탭을 닫을 때도 브라우저의 이탈 확인이 표시될 수 있습니다. 저장하지 않은 내용이 자동으로 복구되는 기능은 없습니다.

사진은 비공개 저장소의 600초 유효 링크로 표시됩니다. 사례를 선택할 때 다시 발급하며, 편집 중에는 4분 간격과 창으로 돌아올 때 사진 링크를 갱신합니다. 이 갱신은 작성 중인 설명과 사진 순서를 저장하거나 덮어쓰지 않습니다. 연결 문제로 사진이 보이지 않으면 우선 입력 내용을 따로 보관한 뒤 목록을 다시 불러오세요.

## 삭제

저장된 사례에서 ‘시공 사례 삭제’를 누르고 내용을 확인한 뒤 ‘삭제 확정’을 누릅니다. 삭제한 사례는 홈페이지에서도 내려가며 관리자 화면에서 복구할 수 없습니다.

사진 정리 중 문제가 생겨 ‘사진 일부는 저장소에 남아 있습니다’라고 표시되어도 사례 삭제 자체는 완료된 상태입니다. 운영 담당자에게 저장소 정리를 요청하세요.
